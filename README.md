# This project was created as part of the 42 curriculum by spaccaud

## Description

This project is a custom library made in C that will be very helpful for future projects at 42. I have reimplemented 26 functions from the standard libc, along with 20 additional functions that handle linked lists, string manipulation, and file descriptors.

## Instructions

To compile the library, you can use the Makefile.

### make

Transforms the C files into object files and compiles them using the flags `-Wall -Wextra -Werror -g`. Then creates the library file.

### clean

Removes all object files.

### fclean

Removes the compiled library file and all object files.

### re

Cleans everything and recompiles the project from scratch (runs `fclean` followed by `make`).
